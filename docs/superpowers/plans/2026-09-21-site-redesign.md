# Site Redesign Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Rebuild The Lawn Care site with a fresh design on a zero-dependency build, and add a mobile menu, sticky quote bar, suburb landing pages, structured data, and a booking-request picker.

**Architecture:** Page bodies live in `src/pages/*.html` with front matter. `scripts/build.mjs` wraps each body in one shared layout (head, header, footer, JSON-LD) and writes flat static HTML to the repo root, where GitHub Pages already serves it. Suburb pages are generated from a data file. Browser logic is split into focused files under `assets/js/`, and the booking-date rules are a pure ES module shared by the browser and `node --test`.

**Tech Stack:** Node 24 (built-ins only: `fs`, `path`, `node:test`, `assert`), vanilla HTML/CSS/JS, Leaflet/Turf (unchanged, CDN), Google Apps Script.

**Spec:** `docs/superpowers/specs/2026-09-21-site-redesign-design.md`

## Global Constraints

- Zero npm dependencies. `package.json` exists only for script aliases.
- Output stays flat static HTML at the repo root. Existing URLs (`index.html`, `services.html`, `quote.html`, …) keep working. `CNAME`, `robots.txt` and `status.txt` stay untouched.
- Never fabricate reviews, stats, job counts, insurance or credentials. Suburb copy says what lawns there are *likely* to be like, not what we have done there.
- No public phone number anywhere. The quote form is the only public contact path.
- Every generated file starts with `<!-- GENERATED by scripts/build.mjs from src/… — edit the source, not this file -->`.
- Every internal URL in sources goes through `{{root}}`.
- Mobile first: 16px minimum gutter, no horizontal scroll at 375px, tap targets at least 44px.
- Respect `prefers-reduced-motion` and `prefers-color-scheme`.
- Booking copy always says *requested* time, confirmed within one business day.

### Task 1: Booking rules module (TDD)

**Files:**
- Create: `assets/js/booking.mjs`
- Test: `tests/booking.test.mjs`

**Interfaces — Produces:**
- `melbourneToday(now?: Date): string` returns `'YYYY-MM-DD'` in Australia/Melbourne
- `addDays(iso: string, n: number): string`
- `weekdayOf(iso: string): number` (0 = Sunday)
- `bookableDates({ today, leadDays, horizonDays, workDays, blackout }): string[]`: calendar days `today+leadDays` through `today+leadDays+horizonDays-1`, filtered to `workDays` and excluding `blackout`
- `windowsFor(iso: string): {id:'am'|'pm', label:string, time:string}[]`: weekend mornings start at 9am (Victorian EPA noise rules for domestic mowers), weekday mornings at 8am
- `isSlotFull(counts: Record<string,number>, iso: string, windowId: string, capacity: number): boolean`, keyed by `slotKey(iso, windowId)` = `` `${iso}|${windowId}` ``
- `formatDate(iso: string): { weekday: string, day: string, month: string, long: string }`

- [ ] **Step 1: Write the failing tests**

```js
import { test } from 'node:test';
import assert from 'node:assert/strict';
import { melbourneToday, addDays, weekdayOf, bookableDates, windowsFor, isSlotFull, slotKey, formatDate } from '../assets/js/booking.mjs';

test('melbourneToday uses Melbourne time (AEST, UTC+10)', () => {
  assert.equal(melbourneToday(new Date('2026-09-21T13:59:00Z')), '2026-09-21');
  assert.equal(melbourneToday(new Date('2026-09-21T14:00:00Z')), '2026-09-22');
});
test('melbourneToday handles daylight saving (AEDT, UTC+11)', () => {
  assert.equal(melbourneToday(new Date('2026-12-01T13:30:00Z')), '2026-12-02');
});
test('addDays crosses month boundaries', () => {
  assert.equal(addDays('2026-09-29', 3), '2026-10-02');
  assert.equal(addDays('2026-12-31', 1), '2027-01-01');
});
test('weekdayOf', () => {
  assert.equal(weekdayOf('2026-09-21'), 1);
  assert.equal(weekdayOf('2026-09-27'), 0);
});
test('bookableDates applies lead time, horizon, work days and blackouts', () => {
  const dates = bookableDates({ today: '2026-09-21', leadDays: 2, horizonDays: 14, workDays: [1, 2, 3, 4, 5, 6], blackout: ['2026-09-25'] });
  assert.deepEqual(dates, ['2026-09-23', '2026-09-24', '2026-09-26', '2026-09-28', '2026-09-29', '2026-09-30', '2026-10-01', '2026-10-02', '2026-10-03', '2026-10-05', '2026-10-06']);
});
test('windowsFor starts weekend mornings at 9am', () => {
  assert.equal(windowsFor('2026-09-21')[0].time, '8am–12pm');
  assert.equal(windowsFor('2026-09-26')[0].time, '9am–12pm');
  assert.equal(windowsFor('2026-09-27')[0].time, '9am–12pm');
  assert.deepEqual(windowsFor('2026-09-21').map(w => w.id), ['am', 'pm']);
});
test('isSlotFull compares open requests with capacity', () => {
  const counts = { [slotKey('2026-09-23', 'am')]: 3 };
  assert.equal(isSlotFull(counts, '2026-09-23', 'am', 3), true);
  assert.equal(isSlotFull(counts, '2026-09-23', 'pm', 3), false);
  assert.equal(isSlotFull({}, '2026-09-23', 'am', 3), false);
});
test('formatDate', () => {
  assert.deepEqual(formatDate('2026-09-23'), { weekday: 'Wed', day: '23', month: 'Sep', long: 'Wednesday 23 September' });
});
```

**Interfaces — Produces:**

- Front-matter keys: `title`, `description`, `path` (output, e.g. `services.html`), `nav` (the current nav key), `robots`, `breadcrumb`, `scripts` (comma list of `site|quote|estimator`), `styles` (`leaflet|admin`), `layout` (`default|bare`), `schema` (`localbusiness|services`), `root` (override), `hero` (`dark|light`).

```js
import { test } from 'node:test';
import assert from 'node:assert/strict';
import { parseFrontMatter } from '../scripts/lib/frontmatter.mjs';
import { createRenderer } from '../scripts/lib/render.mjs';

test('parseFrontMatter reads key: value pairs and strips the block', () => {
  const { data, body } = parseFrontMatter('---\ntitle: Hello: world\npath: a.html\n---\n<h1>x</h1>\n');
  assert.deepEqual(data, { title: 'Hello: world', path: 'a.html' });
  assert.equal(body, '<h1>x</h1>\n');
});
test('parseFrontMatter tolerates CRLF and missing block', () => {
  assert.deepEqual(parseFrontMatter('---\r\na: 1\r\n---\r\nB').data, { a: '1' });
  assert.deepEqual(parseFrontMatter('<p>no fm</p>'), { data: {}, body: '<p>no fm</p>' });
});
const faqs = { svc: [{ q: 'Q1 & more?', a: 'A1' }] };
const r = createRenderer({ config: { business: { name: 'TLC' } }, faqs, suburbs: [{ slug: 'richmond', name: 'Richmond' }] });
test('render substitutes root and config tokens', () => {
  assert.equal(r.render('<a href="{{root}}x.html">{{config.business.name}}</a>', '../').html, '<a href="../x.html">TLC</a>');
});
test('render expands faq sets, escapes text and records them', () => {
  const out = r.render('{{faq:svc}}', '');
  assert.match(out.html, /<details class="faq-item">/);
  assert.match(out.html, /Q1 &amp; more\?/);
  assert.deepEqual(out.faqsUsed, faqs.svc);
});
test('render expands suburb links with root prefix', () => {
  assert.match(r.render('{{suburb-links}}', '../').html, /href="\.\.\/lawn-mowing\/richmond\.html"/);
});
test('render throws on unknown tokens and config keys', () => {
  assert.throws(() => r.render('{{nope}}', ''), /Unknown token/);
  assert.throws(() => r.render('{{config.missing.key}}', ''), /Unknown token/);
});
```
