🗺️ Map engine prototype — MapLibre GL JS

What this is: a side-by-side test of MapLibre GL (WebGL vector-map engine) as a possible replacement for Leaflet on the real quote page. No API key, no account, no cost — same free Esri satellite imagery already used live, just rendered through a different, more modern engine. Not linked from the real site; open this file directly to test locally, then delete it once a decision is made.

What to compare against the live quote.html: pan/zoom smoothness (WebGL vs Leaflet's DOM tiles), and whether "Auto-highlight" reliably paints a visible highlight (this engine reads pixels straight off the rendered map canvas — simpler than Leaflet's tile-stitching approach, which is what caused the invisible-highlight bug you hit).
